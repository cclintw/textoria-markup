閱讀、選取，再用對話標註。

在網頁定位原文，複製資訊到 Codex，說明要新增、修改或清除什麼。說明在目前頁籤開啟；按「返回標註頁」可回到離開前的章節與閱讀位置。

開始使用

  1. 切換正文上方的章節，或從左欄選擇實體。
  2. 點正文中的標註，右欄顯示實體資訊與 KWIC；目前選取的段落排在第一筆。
  3. 點右欄的複製圖示，貼到 Codex 並補上指令。複製只會寫入剪貼簿，不會自動傳送訊息。
  4. 新增、修改、清除都先確認作用範圍，再寫入資料。更新完成後重新整理網頁核對。

本頁的「已有流程」表示現有工具支援；「對話協作」需由 AI 解析、轉換並驗證；「需另行開發」表示尚無內建匯出器。以下提示詞是向 Codex 提出工作的範例，並非每一項都有網頁按鈕。

新增實體 選取與複製已可用

在同一段中反白尚未標註的文字，再點右上角的 ＋。按鈕會複製章回、正文段落號、原文與精確選取範圍。

對話範例

〔貼上「新增」按鈕複製的內容〕
請新增為地點。

Codex 先詢問：「只標註目前選取的這一處，還是全書所有相同名稱？」確認後才處理。全書同名以完整文字精確比對，不自動擴及別名。同名若已有實體主檔，先確認要沿用哪個身分。

跨段、空白或與已有標註重疊的選取會停用新增按鈕；已有標註請使用右欄的複製圖示。

自訂類型 對話協作

新增或修改時直接指定類型即可，不必先手動建立。新類型會在確認操作時一併安排；已有近似類別時，先釐清是否沿用。

〔貼上選取資訊〕
新增為「書院」類型；如果沒有這個類型，請一併建立。

〔貼上實體資訊〕
請把類型改成「寺廟」，先確認影響範圍。

自訂關鍵詞（key-word） 已有清單流程

上傳 UTF-8 的 TXT 或 Markdown 檔，每行一個關鍵詞即可，不需要類型欄或表頭。在對話說「關鍵詞標註」，即使用預設關鍵詞類別；預設類型為 key-word。

檔案範例：key-word-research.txt

大觀園
詩社
婚姻
功名

對話範例

請依上傳的關鍵詞清單進行關鍵詞標註，使用預設 key-word 類型。
確認全書或指定範圍後直接套用，不需審核候選詞表。

關鍵詞按字面比對，不自動補同義詞或語意相近詞。已有實體標註的相同範圍可保留關鍵詞身分；交錯或部分重疊的範圍須另行檢查。

上傳規則表 對話協作

可用自然語言描述條件，也可提供結構化規則或正則表示式。先由 AI 解讀為明確的比對條件，檢查歧義與重疊，再產生預覽。Codex 將說明整理成結構化 JSON，程式執行已支援的正則或前後文條件；無法表達的條件會先說明。

Markdown 檔案範例：rules.md

# 官職標註規則
- 只處理第二回。
- 找出「授」與「一職」之間的文字，標為官職。
- 不跨越句號、問號或換段。
- 若與已有標註重疊，列為待確認，不直接覆蓋。
- 排除「授業」的用法。

對話範例

請依上傳檔案說明標註規則，整理成可重跑的比對條件。
如有規則語意不明請先詢問；確認範圍後直接套用，類型衝突全部保留。

CSV 規則範例

前文,後文,擷取內容,類型,範圍
授,一職,前後文之間,官職,第二回

詞夾子 已有條件引擎

匯出格式與提示詞

右上方「＋」右側依序為 HTML、CSV／Excel、DocuXML。點圖示會複製匯出指令，貼到 Codex 對話框後執行，不會直接下載或自動傳送訊息。匯出一律使用最新正式資料。

單檔 HTML

檔名為「文獻集名稱.html」。包含全書、左側實體清單、右側實體資訊與 KWIC、章節下拉選單和定位；CSS、JS、資料皆內嵌，不需 localhost 或其他檔案。閱讀版移除頂端新增、匯出及說明圖示，保留左右欄開關。

CSV／Excel 詮釋資料表

同時提供「文獻集名稱_metadata.csv」與「文獻集名稱_metadata.xlsx」。第一層章節一列，欄位依 DocuSky metadata 規範；filename 與 DocuXML 的文件編號一致，方便在表格補充標題、作者、年代或來源。表格不包含標註全文，也不是 BatchTagging 批次標記詞表；已完成的正文與逐處標註請用 DocuXML 建庫。將修改後的表格交給 DocuSky 詮釋資料整合工具，可依 filename 對應原件。

DocuXML 建庫檔

檔名為「文獻集名稱_docu.xml」。預設每個第一層章節為一件 document，包含全部下層章節正文；段落以 Paragraph 保存，附原段落 ID、所屬章節與路徑。人物、地點、官職與自訂類型轉為 DocuSky 標記，分類名稱為中文。完整章節樹與原標註 ID 另存於自訂詮釋資料，作為資料保留，不代表 DocuSky 會自動呈現相同的件內目錄。

可直接交給 DocuSky 建庫工具，不必先轉 MARKUS HTML 或 Excel。未套用的重疊匹配不會加入正文。匯出依 DocuXML 1.3 使用四種預設標籤，其他類型使用 Udef_ 自訂標籤並宣告後分類。匯出時會檢查必要欄位、自訂標籤設定、特殊符號、原文、件數與段落 ID；實際建庫相容性仍以 DocuSky 檢測及匯入結果為準。

建立 ChatGPT 網站 對話操作・需 Sites 功能

右上角 DocuXML 圖示右側的地球圖示是「建立 ChatGPT 網站」。點擊只複製指令，不會立即發布。將指令貼到 Codex 對話框送出後，由 AI 使用 ChatGPT／Sites 建立網站，完成後提供網址。

  1. 完成標註核對，再點地球圖示。
  2. 將複製的指令貼到 Codex，確認文獻集後送出。
  3. 系統從最新資料產生展示版，保留左右欄、章節選單、實體定位、功能圖示與說明，再透過 Sites 發布；預設建立私人網站，分享範圍另行指定。
